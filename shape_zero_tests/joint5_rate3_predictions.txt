DERIVATION (done before the run)
For a bump of width sigma -> infinity, |eta^(p - k)|^2 confines the final states to p = k + P,
|P| ~ 1/sigma, on the energy shell d(p) = 0 through k. Near +-k the shell is
    d = (dd/dp_x) P_x + c P_perp^2 + O(P^3),    P_x ~ P_perp^2 / 2 ~ 1/sigma^2,
so to leading order Gamma(+-k) = pi s^2/((2 pi)^q |dd/dw|) * Int d^(q-1)P_perp |eta^(0, P_perp)|^2 / |dd/dp_x|.
|dd/dw| = 2 sqrt(beta^2 c^2 sin^2 k + Q) is the same for +-k; |dd/dp_x| / |dd/dw| = |v_g|.
Hence Gamma(+-k) -> const / |v_g(+-k)|: the wide-bump rate is a DWELL-TIME law, and
    nu_inf(k) = 2 (|v_-| - |v_+|) / (|v_+| + |v_-|),   |v_+| - |v_-| = d(Delta omega)/dk = 2 beta c cos k,
i.e. nu_inf ~ -2 beta Omega cot k. In the continuum drift reading (k << 1) the drift adds V = beta c
to the group velocity and nu_inf = -2V/v_g != 0; on the lattice the drift adds V cos k, which vanishes
at the zone middle. So:
