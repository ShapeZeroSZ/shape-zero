HYPOTHESES
 J1 (instrument) With S small enough that the admixture is <= 0.05 (S_max = min(0.02, 0.001/admix@0.02)),
    epsilon-continuation equals C_pred for every box within max(its error bar, 1%). The records' values
    were the S -> 0 coefficient; the earlier finite-S discrepancies were outside the perturbative range.
 J2 (real) The non-convergence is REAL, not an instrument artifact: measured C_3 at L = 8..24 departs
    between successive sides by more than 10% and more than twice the error bar, with the values of the
    table (sign changes 8 -> 12 -> 16; -0.07, -0.15 at 20, 24). C_2 at 8..24: an isolated outlier at 12
    (+1.92), otherwise -0.04 ... -0.07 -- not converged by 24 (-0.074 -> -0.053, 40%).
 J3 (static) The origin is STATIC in the sense of kappa_side_gpu.py: a fixed property of each box's grid,
    fully given by the second-order kernel -- measured = C_pred, the S^4 term small (|D| S_max^2 < 5% of
    |C|) -- not mode mixing beyond second order ("dynamic": measured != kernel, large S^4 term).
 J4 (mechanism) The dominant terms are a few near-resonant coupled modes (small |d_p(w_k)|). At q >= 2 the
    kernel is not IR-flat: near p = k, d ~ v (p - k)_x + c (p_perp)^2, so along the energy shell transverse
    to k the denominator is second order; with sigma = L/8 the blob's spectral width and the grid spacing
    both scale as 1/L, so the grid samples the singular shell at L-dependent positions and the sum has no
    limit. At q = 1 the shell meets the blob spectrum only at p = k and the kernel is IR-flat (-beta s^2/2),
    so it converges.
