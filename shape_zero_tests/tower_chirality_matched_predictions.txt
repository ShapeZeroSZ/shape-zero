HYPOTHESIS. A' has one radius shared by every component, so a populated background enters every weak
D <= 8 packet as the same extra stiffness dK = sqrt(s); the a-branch (w_a^2 + kappa w_a = Q + dK) and the
b-branch (w_b^2 - kappa w_b = Q + dK) then shift by the same dw = dK/(2 w_a + kappa), and on the same
path feel the same force on the physical wavenumber, dp/dt = -d_x sqrt(s)/(2 w_a + kappa). Nothing in
this depends on which upper components carry s, so it is independent of node size.
