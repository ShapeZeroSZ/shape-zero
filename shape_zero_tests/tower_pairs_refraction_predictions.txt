Recorded results under test: PREMISE_LEDGER C47, C48; MODEL_SPEC 4b.1 "MEASURED" and "TESTED 2026-09-27";
PROVENANCE 6s, 6u.

============================== (1) PAIR CREATION ==============================
HYPOTHESIS. The populated tower's gain into the D <= 8 part is pair creation: the random site- and
time-dependent stiffness Delta = |u| - |u_l| creates (a, b) pairs -- one quantum on each chirality
branch -- stimulated by the packet, so the a-quantum joins the packet and the b-quantum is new.

WHAT IS AN IDENTITY, NOT A TEST. With the populations defined as in the script (N = sum (w_a + kappa/2)
|amplitude|^2 per branch), the D <= 8 charge is EXACTLY N_b - N_a (a change of variables). A' conserves
that charge, so dN_a = dN_b holds identically. Checked, not counted: the identity at t = 0 to <= 1e-10,
and (dN_a - dN_b)/N_a(0) within the charge drift (<= 3e-6).

PREDICTIONS (D16, packet 0.05, T = 2000, all reference-subtracted):
 1a dN_b > 0 in every run with an incoherent tower; dN_b/N_a(0) at T in [2e-4, 1.5e-3] for A_U = 0.005
    (four incoherent components) and 4x-12x larger at A_U = 0.01.
 1b the coherent uniform tower (x = 0): pair rate < 5% of the x = 1 rate.
 1c at fixed mean s the pair rate goes as (var s)^a_p with a_p within 0.3 of the energy-gain exponent
    fitted in the same runs (that exponent expected ~1.07, so a_p in ~[0.77, 1.37]); monotone in x.
 1d the pair part of the gain, dE_b + w0 dN_b, accounts for a fraction of dE_l,self in [0.5, 1.2]
    (seed mean, A_U = 0.005); the a-branch redistribution sum (w_a - w0) dN_a(k) carries the rest,
    either sign, with |fraction| < 0.5; the linear energy dE_a + dE_b is within 20% of dE_l,self.
CRITERIA. SUPPORTED if 1a (sign), 1b, 1c (exponent condition) and a pair fraction >= 0.5 all hold.
 REFUTED if dN_b <= 0 in any incoherent run with A_U >= 0.005, or the pair fraction < 0.2, or x = 0 gives
 >= 25% of the x = 1 pair rate. Otherwise PARTIAL.

=========================== (2) UNIVERSAL REFRACTION ===========================
HYPOTHESIS. A' has one radius shared by every component, so a populated background enters every D <= 8
packet as the same extra stiffness dK = |u| - |u_l|, which for a weak packet (|u_l| << sqrt s) is
sqrt(s). For a mode of the D <= 8 part, w_a^2 + kappa w_a = Q + dK gives dw = dK/(2 w_a + kappa); the
b-branch, w_b^2 - kappa w_b = Q + dK, gives dw = dK/(2 w_b - kappa) = dK/(2 w_a + kappa): the same.
So the STIFFNESS SHIFT dK is universal -- the same for both chiralities, every carrier, every colour,
every node size -- while the frequency shift and the deflection force on the wavenumber scale with the
packet's own 1/(2 w_a + kappa). Universality is expected only for weak packets: a strong packet's own
amplitude is part of the shared radius and lowers the dK it senses.
Frequencies (kappa* = 0.971737): w_a(pi/4, pi/2, 3pi/4) = 1.2628, 1.6289, 1.9403; 2 w_a + kappa = 3.497,
4.229, 4.852; so at dK = 0.01 the shifts are dw = 2.859e-3, 2.364e-3, 2.061e-3.

PREDICTIONS
 2a weak probes (1e-4) in the coherent uniform background (<s> = 1e-4, sqrt = 0.01):
    dK_eff / sqrt<s> in [0.98, 1.00] for every kind (the probe's own |u_l| lowers it by < 1%); spread
    across chirality, carrier, colour and node size (max - min)/mean <= 0.02; a and b at the same k0
    within 1%; dw in the ratios above.
 2b weak probes in the incoherent background (A_U = 0.005): a and b within 2%; dK_eff / <sqrt s> in
    [0.95, 1.05]; <sqrt s> / sqrt<s> ~ 0.97 (four components).
 2c amplitude (a-branch, pi/2, coherent background) -- predicted NON-universal: dK_eff / sqrt<s> =
    [0.90, 0.97] at 1e-3, [0.45, 0.80] at 1e-2, [0.10, 0.25] at 5e-2.
 2d deflection in the gradient (density rising toward +x at the packet; weak probes):
    - the physical wavenumber is pushed AWAY from the denser region for every kind: dp < 0;
    - dp matches the ray prediction integral F/(2 w_a + kappa) dt to within 5% (ratio in [0.95, 1.05]);
      |dp(T)| in [0.5e-3, 2.5e-3];
    - a and b at the same k0 agree within 5% (by the symmetry of the profile about x0 they sample mirror
      gradients); D16, D32, D64 agree within 2%; dp (2 w_a + kappa) agrees across k0 within 20% (the
      carriers move at different speeds and sample different gradients);
    - the DISPLACEMENT is not universal in sign: it follows the lattice group-velocity curvature
      dv/dp, which is the same function of p for both branches: away from the denser region (dx < 0)
      at k0 = pi/4 (dv/dp = +0.31), toward it (dx > 0) at 3pi/4 (dv/dp = -0.33) and, weakly, at pi/2
      (dv/dp = -0.11); |dx(T)| of order 0.005 - 0.05 sites; measured dx within 30% of the script's
      predicted dx, same sign.
CRITERIA. Universal refraction SUPPORTED if: 2a's spread <= 0.02 and ratio in [0.98, 1.00]; 2b's a/b
 agreement within 2% and ratio in [0.95, 1.05]; 2d's dp < 0 for every kind, ratios in [0.95, 1.05], a/b
 within 5% and D16/D32/D64 within 2%. REFUTED if chirality or node size changes dK_eff or dp by more
 than 10%, or dp > 0 (toward the denser region) for any weak probe. Otherwise PARTIAL.
 2c and the displacement signs are predictions, not criteria for universality.

PREDICTED OUTCOME: pair creation SUPPORTED; universal refraction SUPPORTED in the weak-packet limit, as
a universal stiffness shift -- not a universal frequency shift or displacement.
